## Getting Started

- **Requirements**: `Node >= 18`
- **Install**: `npm i` 
- **Test**: `npm test` 
- **Deploy**: contracts deploy per release with `scripts/create2/deploy.js`. Each release's steps are in `release/<version>/release-<version>.md`.
- **Deployments package**: `npm run deployments:build` builds the ABIs and addresses package. See [deployments/README.md](deployments/README.md).
